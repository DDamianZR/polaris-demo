# Polaris · demo web

Rama aislada para una demo web. No comparte historial ni archivos con el bot de Polaris.

## Reglas
- Nunca se mezcla con `master` ni con las ramas de fase (`f<n>-*`). Git lo rechaza solo, porque los historiales no tienen relación. No uses `--allow-unrelated-histories`.
- No importa ni modifica código del bot. Si la demo necesita algo de ahí, se copia aquí.
- No toca `data/polaris.db`, las tareas programadas ni el llama-server de la laptop.
